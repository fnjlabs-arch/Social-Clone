Questions, answered honestly

Which devices does Social Clone work on?

Android phones, for now. Download the app directly from the button on this page.

Is Social Clone on the Play Store?

Not yet. The Android app is available as a direct download from this site.

Does it include a VPN?

No. There is no bundled VPN in phase 1.

How does a license code work?

Paste the code into the app’s single activation field. The app detects whether it is a 5-profile (SC5) or 10-profile (SC10) code automatically. In the current build, activation works offline on the device. Device-bound licensing will arrive with the teacher dashboard; it is not live yet, and this site does not promise it today.

Can I browse the whole web in it?

No. Social Clone is a TikTok and Facebook kiosk only — no Gmail, no address bar, no general browsing.
